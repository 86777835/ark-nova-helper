# 方舟动物园助手 · 做 / 不做清单（待确认）

调研日期 **2026-11-05**。完整报告在 [调研/](调研/)：英文社区、中文社区、已有工具、规则资料与版本差异四份。BGG Files **190 个去重条目**，定向读 **4 帖 / 80 楼正文**；集石取得 **10 条近期评测条目**，另核查 B 站资料。小红书被登录页阻挡，贴吧只取得搜索摘要与吧信息，没有完整讨论样本。数字表示采样范围，不是痛点发生率。

## 先说六个事实

- **方舟多人没有固定轮次。**适合“随时查规则、需要时打开休息清单、终局每人填分”，不应照搬奥丁的固定阶段轮转。[基础规则 p6、18–19](https://capstone-games.com/cdn/shop/files/Ark-Nova-Rulebook.pdf)
- **新旧计分并存，新分＝旧分＋100。**新规则是最终魅力加保护格的小白字，不能直接把魅力和保护点数相加；这不是海洋扩展专属改动。Capstone 当前英文 PDF 仍写旧方式，Feuerland 德文 V2 已更新。[官方更新](https://boardgamegeek.com/thread/3057107/2-rules-updates-for-ark-nova)、[德文 V2 p19](https://www.feuerland-spiele.de/fileadmin/game/Arche_Nova/AN_Rules_DE_V2_0_Web.pdf)
- **海洋世界需要换牌和轮抽，不是全部混进去。**81 张新卡＋38 张替换卡；每人轮抽两张不同类型变体行动。它没有附新动物园地图，地图包另算。[海洋官方规则](https://capstone-games.com/cdn/shop/files/AN_Exp1_Rules_EN_0-7_low.pdf)
- **正式简中为《方舟动物园》《方舟动物园：海洋世界》，中文出版品牌是游人码头。**核心词用“魅力、保护点数、保护项目、声望、休息”；“吸引力、保育点”可留作搜索别名。[官方产品页](https://www.gameharbor.com.cn/zh/game/detail/ArkNova)、[官方简中 FAQ](https://www.gameharbor.com.cn/uploads/GameDownloads/1689920075_28b06eb8fb67fd7182dc.pdf)
- **计分防错与规则速查有直接需求证据。**英文玩家困惑新旧分数，中文玩家明确提育儿袋图标和协会任务错误；BGG 一页辅助 **64 赞**、计分转换表 **16 赞**。不据这些数字宣称资源账本或地图编辑器是刚需。[英文报告](调研/调研_英文社区.md)、[中文报告](调研/调研_中文社区.md)
- **已有计分 App、网页随机器和 ARNO 单人助手。**新站应集中解决中文、版本过滤、少输入、防重复加分及系列存档；不重复做完整自动对手或线上游戏。[工具对比](调研/调研_已有工具.md)

## 要你决定的三件事

**A. 计分默认用新版还是旧版？建议默认新版，同时显示旧版对照。**

- 新版有官方依据，也更容易与 BGA 成绩沟通；旧盒玩家仍可输入原始保护点数，由助手换算，不要求自己寻找不存在的小白字。
- 保存原始两轨和显示口径，历史可按同口径比较。排名规则不变，不把新版分误当额外奖励。[官方更新](https://boardgamegeek.com/thread/3057107/2-rules-updates-for-ark-nova)

**B. 官方单人要不要首版做计步器？建议先做资料与结算；如果你经常单人玩，再加可撤销的 27 回合计步。**

- 单人确实存在误数与提前结束案例，但首版计步会要求每个常规回合操作手机，需要权衡是否比实物方块方便。
- 若做，只跟踪官方 7/6/5/4/3/2 回合，不计每个额外行动，不重写 ARNO。[单人纠错帖](https://www.reddit.com/r/soloboardgaming/comments/11tgmpq/ark_nova_total_33_after_finishing_3rd_break/)

**C. 地图包首版支持到哪里？建议基础地图＋完整海洋；地图包 1 优先，地图包 2 等你确认持有/常玩再做。**

- 包 1 有正式简中资料；包 2 的储牌、收入、行动强度有额外例外，需要逐图核验。地图编号可以先记录，但“完整支持”应意味着有对应规则提示。
- Arcade 推广卡和 BGA 替代地图先给资料链接，不默认为本局使用。[地图包与推广内容目录](调研/调研_规则资料与版本差异.md#7-官方地图与推广内容)

素材小项也留待开发前确认：**保留现有英文盒面，还是使用已找到的高清德文官方平面盒面**。现图是合格平面图但只有 591×720；高清德文图为 1642×2000。推荐语言能接受就用官方高清德文图，否则继续找英文高清平面图，不拿立体盒照替代。[封面核验](调研/调研_规则资料与版本差异.md#8-封面只记录链接未下载原图)

## 不做（留在线下或明确暂缓）

| 环节 | 理由 |
|---|---|
| 全程魅力/保护/声望三轨、钱币、X 标记账本 | 实物轨道与筹码已经清楚，重复输入会不同步；只在终局录最终数值 |
| 五张行动卡拖拽、升级状态同步、强制回合打卡 | 线下滑牌快，手机镜像增加操作；普通多人没有固定轮次，不做奥丁式轮数推进 |
| 地图格子编辑、自动最优拼法、拍照识别得分 | 地形摆放是游戏本体；输入与识别成本高，也没有可靠方案的验证证据 |
| 线上手牌、抽牌堆、展示区、隐藏终局卡同步 | 超过线下辅助范围，且要求录入隐藏信息；开局只给实物检查表 |
| 全卡牌图片库、自动连锁引擎 | 版本和印次维护重；先做少量有出处的规则与卡号速查，不重建完整数字游戏 |
| 自动计算每次动物成本、赞助商全部触发条件 | 需要知道全场牌与图标，反而逼玩家全程录牌。先提供条件/折扣规则说明 |
| 独立“海洋奖励总分”分类 | 扩展效果归入原两轨；凭空再加一栏容易重复计分 |
| ARNO/HANNA 自制对手引擎 | ARNO 已有成熟网页；先给入口，避免混淆官方单人规则 |
| ELO、竞技成就、逐回合得分归因、最佳行动推荐 | 偏线上竞技或要求额外记录，首版没有足够需求依据 |
| 强制计时、自动限时 | 慢局反馈不等于玩家要求计时；先减少助手本身的操作 |
| 自制扩展、任意拆分海洋模组、Sanctuary | 本轮范围是基础＋海洋，另调查官方地图/推广内容；不引入未经核实组合或独立衍生游戏 |
| 在线直接玩、部署、建仓库、Git 操作 | 用户明确排除；本轮只交调研文档 |

以上是实物优先原则与证据权衡，不是宣称这些功能永远无人需要。[证据和限制](调研/调研_英文社区.md)
