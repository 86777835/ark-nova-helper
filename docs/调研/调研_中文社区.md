## 3. B 站：规则争议与工具需求

- [《关于综合研究员和放生，你可能不知道的7条冷知识》](https://www.bilibili.com/opus/924547536465690628)：集中讨论放归和转移时翻哪个饲养区、山水需求、户外营地。作者自己标注部分推断“并不一定准确，仍需要验证”。**它证明问题值得查，不作为最终裁定**；本轮以游人码头官方 FAQ 与海洋规则交叉核查。
- [《Map1～Map10地图特性分析》](https://www.bilibili.com/opus/921995522734030899)：作者自述 300+ 场、最高 ELO 563、最高排名 18，明确主要是二人局，还更正过旧版说法。可见地图能力和摆放规划很复杂，但这是个人策略样本，不能把这些数字写成群体统计，也不适合做实时最佳行动推荐。
- [《BGA桌游规则：方舟动物园》](https://www.bilibili.com/opus/1030057071735734295)：2025-02-04 发布中文规则图片。是社区转载入口，不是出版社官网 PDF。[集石“官方规则书”转载页](https://www.gstonegames.com/game/doc-4505.html)也提供图片，页面标“来源：其它”，应保持这个身份区别。
- [《历年真题每日打卡》](https://www.bilibili.com/video/BV1jM4m127K9/)：工具作者发布选卡挑战，页面检索快照为 **4,545 播放、15 弹幕、94 赞、48 投币、39 收藏**；数字是搜索缓存而非实时 API。它说明中文玩家有练习与选卡讨论需求，但属于局外学习。作者链接的[每日挑战](https://ark-nova.ender-wiggin.com/zh-CN/quizzes)不应成为本助手强制步骤。

## 4. 出版方与正式简中用词

原出版方为 **Feuerland Spiele**，英文出版方 **Capstone Games**；中文发行品牌为 **游人码头（Game Harbor）**。游人码头[官方产品页](https://www.gameharbor.com.cn/zh/game/detail/ArkNova)明确列简体/繁体中文，并列基础版《方舟动物园》、扩展《方舟动物园：海洋世界》以及《方舟动物园：地图推广包#1》。BGG Chinese edition 591904 也列 Game Harbor。不要把零售商集石写成中文版出版方。

本次取得游人码头[官方简中 FAQ/勘误 PDF](https://www.gameharbor.com.cn/uploads/GameDownloads/1689920075_28b06eb8fb67fd7182dc.pdf)，全文可提取。术语以下表为站点建议基准：

| 英文 | 建议采用的简中词 | 备注与核验位置 |
|---|---|---|
| Ark Nova / Marine Worlds | 方舟动物园 / 海洋世界 | 官方产品页 |
| Appeal | **魅力** | FAQ 卡牌 251 使用“2魅力”；“吸引力”可作为搜索别名 |
| Conservation points | **保护点数** | FAQ 日本猕猴条目；不直接写成“胜利分” |
| Conservation Project | **保护项目** | 官方产品页、扩展中文扫描；“保育项目”作为别名 |
| Reputation | **声望** | 官方产品文案为“科研声望”，规则中可见“声望记录条” |
| Break | **休息** | 官方 FAQ 卡牌 251 和单人条目 |
| Enclosure / Special enclosure | **饲养区 / 特殊饲养区** | 官方 FAQ 开头勘误 |
| Association / Partner zoo | **协会 / 合作动物园** | 官方 FAQ 图标与升级条目 |
| Sponsor / Final Scoring card | **赞助商 / 终局计分卡牌** | 官方 FAQ、产品页 |
| Kiosk / Pavilion | **贩售亭 / 休憩亭** | 官方 FAQ 地图 A 示意 |
| X-token / Multiplier | **X标记 / 双重标记** | 官方 FAQ 催眠与奖励板块 |
| Release into the wild | **放归野外** | 官方 FAQ；“放生”是社区常用说法 |
| Aquarium / Reef Dweller / Wave | **海洋馆 / 珊瑚住客 / 海浪图标** | 海洋中文版扫描转载；出处级别低于官网直供 PDF，开发前宜逐张实物复核 |
| Alternate Action card | **变体行动卡牌** | 同上海洋中文扫描 |

海洋中文[扫描及转录入口](https://zhibinai.cn/games/ark-nova-marine-worlds.html)说明包含 **8 页规则＋8 页术语表**，并指向微信原转载。它不是官方托管站。网页转录本身存在生硬句和潜在误录，例如把英文“functionally identical”写成具有独特功能；**不要整段复制到规则助手**。机制以英文官方规则核验，中文专名优先核对原书图像或实物。

## 5. 中文资料还缺什么

游人码头当前产品页只直供 FAQ、地图包 1 简繁规则，未找到基础和海洋完整规则的官方直供 PDF。已记录集石/B 站基础规则图片和海洋中文扫描入口，但不宣称已经取得两本官方简中 PDF。首版可建立已有证据充分的中文速查；开发完整逐卡问答前，仍需补齐中文正文、术语表与印次核验。小红书与贴吧完整讨论亦未取得，不能用虚构样本补足。
